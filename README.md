# The Edge Weave — B2B Website

A responsive, static, single-page website with Home, Products, Customisation, About and Request a Quote sections.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive styling and concept product illustrations
- `script.js` — mobile menu, product selection and email quote flow

## Preview locally
Open `index.html` in your browser. Internet access is optional; the design uses system font fallbacks if Google Fonts are unavailable.

## Publish for free with GitHub Pages
1. Create a public GitHub repository (for example `edgeweave-site`).
2. Upload the three website files into the repository root.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Wait for GitHub to provide your live `github.io` URL.
5. Optional: buy a domain later and configure it under **Settings → Pages → Custom domain**, following GitHub's DNS instructions.

Alternative: drag the website folder into Cloudflare Pages' direct-upload deployment interface, following Cloudflare's current instructions.

## Quote form — important
This is a static website. The quote form **does not send email automatically** or save data. It opens the visitor's email application with a pre-filled message addressed to edgeweave@gmail.com. The visitor must click Send. For automatic form submissions later, connect a verified third-party form service and update the privacy disclosure.
